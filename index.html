How it works

Every character and word is picked with crypto.getRandomValues and rejection sampling, so no character is more likely than another (no modulo bias). "Require each set" regenerates until the rule holds, which keeps every valid password equally likely; the entropy shown counts exactly how many such passwords exist. Passwords are never saved: only your option choices are remembered on this device.
